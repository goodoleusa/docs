The `deploy/` package contains everything you need to run faerie2 in production. It bundles OpenHands, the faerie2 MCP server, and an optional nginx reverse proxy into a single Docker Compose stack.

## What you get

- **OpenHands** runtime on port `3000` for agent execution.
- **MCP server** on port `8080` exposing six faerie2 orchestration tools.
- **Nginx + Certbot** on ports `80`/`443` for TLS and reverse proxying (VPS only).
- **Chat MVP** UI as an optional front-end.

## Choose a target

| Target | When to use | Compose file |
|---|---|---|
| VPS | Public internet, custom domain, TLS | `deploy/docker-compose.prod.yml` |
| ZimaBoard | LAN-only, ARM64, no nginx | `deploy/zima/docker-compose.yml` |
